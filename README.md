# 게놈의 탑 · 규칙 설명과 게임 진행

[애니메이션 발표본](https://mingeun0507.github.io/genome-briefing/) · [설명 PDF](./게놈의_탑_플레이_브리핑.pdf)

![표지](./preview.png)

7인 머더 미스터리 《게놈의 탑》의 원문 스토리, 시작 전 공통 규칙, 설명서 순서에 맞춘 진행 화면. 총 44장.

## 구성

- 시작 전 공통 규칙: 밀담·조사·카드 관리·의학적 지식 협력·녹음기·정보 공유 설명과 단계별 시연.
- 스토리: 인트로·메일·사건 발생·오프닝·안전확인 원문 46개 문단 수록. 줄바꿈과 문단 배치만 정리.
- 진행 화면: 설명서 ①~⑬ 순서. 설정서 읽기·조사·정보 공유·추리의 제한 시간과 할 일 표시.
- 상황 삽화 2장과 궤도 엘리베이터·유리 너머 목격 관계 설명도 포함.
- 모바일에서는 본문과 그림을 한 열로 표시. 밀담·조사·의학적 협력·녹음기·정보 공유는 휴대폰용 단계별 그림으로 설명. 캐릭터 표만 개별 가로 이동 가능.

## 조작

- `→` 또는 `Space`: 다음 단계·다음 장
- `←`: 이전 단계·이전 장
- `M`: 목차
- `F`: 전체화면
- `게임 시작`: ① 인트로로 이동
- `소희 음성 재생`: 스토리 화면 진입 시 한국어 여성 목소리 소희 자동 재생. 음성이 끝나면 다음 화면으로 이동하며, 다음 화면도 스토리일 때 이어서 재생. 기본 1.75배속이며, 배속 선택 메뉴에서 1~2.5배로 조절 가능. 규칙·진행 화면에 도달하면 자동 재생 정지. 수동 정지는 현재 화면 유지.
- 브라우저가 첫 자동 재생을 막으면 `소희 음성 재생` 버튼을 한 번 눌러 시작.
- `음성 재생` / `음성 정지`: 나머지 규칙·진행 화면을 브라우저의 한국어 음성으로 읽거나 중단.
- 단계별 타이머: 직접 시작·일시정지·계속·초기화. 다른 단계에서 새로 시작하면 이전 타이머는 남은 시간을 보존한 채 일시정지.
- 다른 화면에서도 상단에 현재 타이머 표시. 화면 이동이나 녹음기 낭독으로 시간이 멈추지 않으며, 종료되어도 자동으로 다음 단계로 넘어가지 않음.
- 1인 발표는 `다시 1분`으로 초기화한 뒤 다음 사람의 시간을 직접 시작.
- `메뉴 숨기기` / `메뉴 보이기`: 하단 목차·이동 바 표시 전환. 숨긴 상태에서도 음성·복구 버튼 유지.
- 진행 화면의 규칙 버튼: 공통 규칙으로 이동
- `진행 화면으로`: 규칙을 확인하기 전의 진행 화면으로 복귀

`index.html`을 브라우저로 직접 열어도 동작. 스토리 음성은 `audio/` 폴더, PDF 다운로드는 PDF를 같은 위치에 유지해야 동작.
단계 제한 시간은 화면 안 타이머로 관리. 시작·일시정지·종료 상태와 남은 시간은 브라우저에 저장하며 새로고침 후에도 유지.
스토리 음성은 Qwen3-TTS CustomVoice의 한국어 목소리 Sohee(소희)로 생성한 MP3. 정상 속도 파일을 사용하며 기본 재생 속도는 1.75배. 재생 중에도 1·1.25·1.5·1.75·2·2.5배로 조절 가능하고 선택한 속도는 브라우저에 저장. 모델·개인 참조 녹음·참조 대본은 게시하지 않음.
규칙·진행 화면은 브라우저의 한국어 읽기 기능 사용. 설치된 음성·브라우저에 따라 목소리와 지원 여부가 다를 수 있음.
